# Telegram Bot — каталог 8 уровней

Готовая версия с новой лестницей каталога:

1. Бренд
2. Категория
3. Серия — необязательная
4. Модель
5. Симка — необязательная
6. Память
7. Цвет
8. Карточка товара

Если серия или симка не указаны для выбранной ветки, клиент этот шаг не видит. После выбора цвета бот сразу открывает карточку товара, если по выбранным параметрам найден один товар. Если товаров несколько, покажет список товаров.

## Как заменить

На Railway/GitHub оставьте структуру:

```text
bot.py
parts/
  00_config_env.py
  01_order_beauty.py
  02_database.py
  03_catalog_db.py
  04_orders_admins_db.py
  05_keyboards.py
  06_state_helpers.py
  07_jobs_commands.py
  08_text_handler.py
  09_photo_handler.py
  10_callback_handler.py
  11_main.py
requirements.txt
Procfile
```

Start command остаётся:

```bash
python bot.py
```

## Массовое добавление товаров

В админке нажмите `📦 Массовое добавление каталога` и отправьте строки.

Основной формат:

```text
Бренд | Категория | Серия | Модель | Симка | Память | Цвет | Полное название товара | Цена | Описание
```

Серия и симка необязательные. Можно поставить `-`.

Пример:

```text
Apple | Смартфоны | 15 серия | iPhone 15 Pro | eSIM | 256GB | Blue | iPhone 15 Pro 256GB eSIM Blue | 118000 | Новый, оригинал
Apple | Смартфоны | - | iPhone 15 | - | 128GB | Black | iPhone 15 128GB Black | 89000
```

Короткий формат без серии и симки:

```text
Бренд | Категория | Модель | Память | Цвет | Полное название товара | Цена | Описание
```

Пример:

```text
Apple | Смартфоны | iPhone 15 | 128GB | Black | iPhone 15 128GB Black | 89000
```

## Массовое обновление цен

Формат остался по ID:

```text
25 = 118000
26 = 132000
```


## Редактирование уровней каталога

В админ-панель добавлены отдельные редакторы для каждого пункта лестницы:

- бренд;
- категория;
- серия;
- модель;
- симка;
- память;
- цвет;
- товар.

Через редактор уровня можно переименовать пункт сразу во всех товарах, где он используется. Для серии и симки можно отправить `-`, чтобы очистить поле. Удаление пункта скрывает все товары, в которых этот пункт используется.

- В админ-панель добавлена кнопка `📋 История заказов`: показывает историю за последние 3 дня. Одинаковые товары внутри одного заказа объединяются и отображаются количеством, например 10 шт. одной строкой.

## Хранение заказов

История заказов сохраняет количество товара в одной строке заказа. Заказы автоматически ограничиваются по размеру: по умолчанию таблица заказов хранится до 3 ГБ. Когда лимит достигнут, бот удаляет самые старые заказы целиком и оставляет новые.

При необходимости лимит можно изменить в Railway Variables:

```bash
ORDERS_STORAGE_LIMIT_GB=3
```
